# Retail Sales and Customer Insights

A Data Analytics project using Python, SQL concepts and Power BI to analyze retail sales performance and customer behavior.

## Project Overview
This project analyzes the Sample Superstore dataset to identify sales trends, customer segments, product category performance and regional insights.

## Tools & Technologies
- Python
- Pandas, NumPy, Matplotlib, Seaborn
- Jupyter Notebook / Google Colab
- Microsoft Power BI
- Excel

## Key Performance Indicators
- Total Sales: $2.30M
- Total Profit: $286.40K
- Total Orders: 5,009
- Total Customers: 793

## Dashboard Features
- Sales Performance Analysis
- Category and Segment Analysis
- Regional Sales Comparison
- Monthly Sales Trend
- Interactive Region and Segment Filters

## Project Files
- `notebooks/` – Python analysis notebook
- `reports/` – Project documentation
- `Superstore Sales Dashboard.pbix` – Power BI dashboard

Sample Superstore retail dataset.
